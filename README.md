# Torre de Controle Operacional

Dashboard executivo dark/neon para centralização dos indicadores de operações da rede.

## Executar no Codespaces

Como a aplicação é estática, rode no terminal:

```bash
python3 -m http.server 5173
```

Depois abra a porta **5173** na aba **PORTAS** do Codespaces.

## Telas

- Visão Executiva / Torre de Guerra
- PDV & Cliente
- Comercial
- Estoque & Logística
- Inventário
- Pessoas
- Financeiro
- SAC & Eficiência

## Escopo atual

Interface funcional com dados demonstrativos (mock) e navegação completa. O código está separado em `index.html`, `styles.css` e `app.js`, pronto para posterior conexão às APIs e bases corporativas.
